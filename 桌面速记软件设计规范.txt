────────────────────────────────────────────────────────────────────────
一、产品概述
────────────────────────────────────────────────────────────────────────

  轻提词（MicroPrompt）是一款面向 Windows 10/11 的轻量级桌面笔记软件，采用
  单窗口、左右分栏布局，提供富文本编辑与本地持久化存储。软件强调
  流畅的视觉过渡、自然的渐变动效与细腻的交互反馈，整体风格为
  Win11 现代浅色风。

  核心定位：
    · 极简操作：所见即所得，一条笔记从新建到保存全程无需弹窗
    · 自动保存：输入即存，数据零丢失风险
    · 沉浸体验：启动/退出/切换均有精心设计的动画与音效

二、开发技术栈
────────────────────────────────────────────────────────────────────────

  ┌────────────────┬────────────────────────────────────────────────┐
  │ 语言           │ C++17（CMAKE_CXX_STANDARD 17）                 │
  │ 框架           │ Qt6（Qt6::Widgets、Qt6::Svg）                   │
  │ 构建系统       │ CMake ≥ 3.16，启用 AUTOMOC/AUTORCC/AUTOUIC     │
  │ 编译器         │ MSVC（/O2 /GL 优化），Release 默认               │
  │ 平台 API       │ DWM 窗口圆角、MCI 音频播放（winmm）             │
  │ 样式           │ QSS（Qt Style Sheets）+ 控件自绘（QPainter）     │
  │ 图标           │ SVG 矢量图标，自研 SvgIconLoader 着色加载       │
  │ 数据存储       │ JSON（%APPDATA%/MicroPrompt/notes.json）       │
  │ 崩溃防护       │ CrashHandler，闪退时在 exe 目录写 crash.log     │
  │ 高 DPI         │ PassThrough 缩放策略，图标按 DPR 重新渲染       │
  └────────────────┴────────────────────────────────────────────────┘

  开发规范约束：
    1. 所有动画必须使用非线性缓动曲线（OutCubic/InCubic/OutBack）
    2. 所有控件遵循 RAII 原则，动画对象 DeleteWhenStopped 自动释放
    3. 窗口必须保持无边框自绘风格，不启用系统默认标题栏
    4. 新功能优先自绘 QPainter 实现，保证视觉统一

────────────────────────────────────────────────────────────────────────
三、软件功能
────────────────────────────────────────────────────────────────────────

  3.1 笔记管理
    · 新建笔记（列表头部"+"图标按钮，默认标题"新建笔记"）
    · 删除笔记（列表头部删除按钮 / 卡片右键菜单，带确认弹窗）
    · 重命名笔记（卡片右键菜单 → 输入对话框）
    · 选中最近修改的笔记自动恢复上次编辑位置
    · 笔记卡片展示标题 + 建立时间（yyyy-MM-dd HH:mm）

  3.2 富文本编辑
    · 字号选择：10 / 12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 pt（默认 10pt）
    · 格式刷：一键复制当前光标处的格式（字号/粗体/下划线/删除线/颜色），
      点击后选中目标文字自动应用；Esc 或再次点击按钮取消
    · 粗体、下划线、删除线（可勾选，选中态底部深灰指示条）
    · 文字颜色：红 / 蓝 / 绿 / 白 / 黑 五色（圆形色块选择）
    · 插入水平分割线（独占一行，不额外插入空行；线上下留白由分割线
      块的固定行高提供，默认块高 22px）；右键分割线图标可切换样式：
      实线 / 虚线 / 点线 × 细 / 中 / 粗（共 9 种），二级菜单与右侧
      笔记列表右键菜单同款视觉（白底圆角/浅灰边框/上浮淡入），尺寸更紧凑
    · 回到笔记底部（一键光标跳至文末并聚焦）

  3.3 编辑区背景
    · 纯白背景（#FFFFFF）
    · 类纸张黄背景（#FFF8E7）

  3.4 窗口控制
    · 置顶/取消置顶（图钉按钮，旋转动画，Win32 SetWindowPos 实现）
    · 最小化（220ms 淡出后隐藏，不使用系统动画）
    · 最大化/还原（约束在工作区内，不遮挡任务栏；图标联动切换）
    · 关闭（退出动画：界面淡出 + 中央图标淡入 + "再见"音频）

  3.5 自动保存机制
    · 输入防抖：停止输入 500ms 后落盘
    · 兜底保存：每 2s 检查脏标记，防抖被中断时强制补写
    · 失焦保存：编辑器失焦立即保存
    · 关闭保存：关闭时强制保存，失败重试最多 3 次
    · 原子写入：写临时文件 → 读回校验 → 备份旧文件 → 替换

  3.6 启动与退出
    · 启动：播放"Hello"音效，图标桌面中央淡入（420ms）→ 停留
      （140ms）→ 图标淡出 ∥ 主窗口淡入（450ms）
    · 退出：界面淡出（480ms）∥ 图标淡入（380ms）→ 播放"再见"
      音频并停留至音频结束 → 图标淡出（320ms）→ 真正退出

  3.7 其他
    · 状态提示：顶栏中部显示"笔记名称 / 编辑"、"笔记名称 / 保存中"
    · 崩溃日志：crash.log 记录闪退现场
    · 窗口边缘 6px 缩放区域，标题栏拖动与双击最大化

  4.1 窗口尺寸
    · 默认尺寸：880 × 560
    · 最小尺寸：640 × 420
    · 顶栏高度：44px
    · 左右分割：默认 260 : 620，分割条 1px，禁止折叠子窗格
    · 窗口边缘缩放区域：6px

  4.2 布局层次
    · 主背景 #F3F3F3
    · 顶栏 #FAFAFA，下边框 1px #E5E5E5
    · 列表面板 #FAFAFA，右边框 1px #E5E5E5
    · 编辑器面板 #FFFFFF

  4.3 左侧列表元素命名
    为便于交互与开发文档对照，左侧列表各元素统一命名如下：

    · 笔记列表组（代码：NoteListGroup）
        左侧列表中的单个笔记条目。将笔记列表边框、边框内的笔记名称
        与创建日期时间深度绑定为一个整体，全部由控件自绘（QPainter），
        缩放/移动时各元素同步运动。固定高 50px，透明底 + 1px 描边
        （#E5E5E5，与左右分栏分隔线同宽同色），圆角 15px。
        选中时卡片右侧有一段横向黑色渐变（靠右略深，向左渐变融入
        列表面板背景色 #FAFAFA），无整卡填充。
    · 列表文字（组内自绘文本）
        笔记标题与建立日期文字，由笔记列表组自绘、随整组联动。
        正常态与选中态均保持深色（标题 #3B3B3B、日期 #9A9A9A），
        选中态仅由右侧黑色渐隐标识，文字不换色。
    · 悬停放大
        鼠标悬停/经过笔记列表组时，整组轻微放大（约 1.03 倍），
        缓动曲线进入 OutCubic / 离开 InCubic，动画 100ms；
        放大后整组不超出左侧列表区域、不被裁切；响应速度快，
        鼠标快速滑动时各组实时跟随。
    · 选中插卡
        鼠标左键选中笔记列表组时，整组整体向右平移并同步收窄宽度
        （右边缘贴住列表区域右边界，左侧留出空隙），像插卡插入右侧
        插槽；切换到其他组时旧组向左收回原位。动画 220ms，
        选中 OutCubic / 收回 InCubic。选中后常驻右侧黑色渐隐填充。

    · 全部采用 SVG 矢量源，运行时经 SvgIconLoader 替换 fill 颜色
    · 图标以 2 倍尺寸预渲染为 QPixmap（高清），动画期间仅 alpha

    · 高 DPI 下按 devicePixelRatioF() 重新生成，避免模糊与溢出
    · 图标逻辑尺寸 1:1 映射物理像素居中绘制

  6.4 图标库约定
    · 全部 SVG 统一存放于 icons/ 目录并打包为 Qt 资源（qrc）
    · 内置资源：app-logo、close、maximize、minimize、pen、pin、

      underline、strikethrough、divider、palette、arrow-down
    · 新增图标优先放入 icons/ 目录、使用英文命名并保持单色可着色

八、动画与动效规范
────────────────────────────────────────────────────────────────────────

  8.1 缓动曲线
    · 进入/悬停/展开：OutCubic（先快后慢）
    · 退出/收起：InCubic（先慢后快）
    · 图钉旋转：OutBack（带回弹）
    · 禁止使用线性曲线，避免生硬感；动画全程无抖动

  8.2 动画参数表
  ┌──────────────────────────┬────────┬──────────────────────────────┐
  │ 动画                     │ 时长   │ 曲线                         │

十三、未来更新计划（V3.0 展望）
────────────────────────────────────────────────────────────────────────

  本章节为规划中的功能设计草案，正式开发前需经评审确认细节。
  计划共两项：
      · 计划一：代码引用块（Reference Block）
      · 计划二：AI 提示词优化助手

  ──────────────────────────────────────────────
  13.1 计划一：代码引用块（Reference Block）
  ──────────────────────────────────────────────

  13.1.1 功能背景与目标
    本软件常被用于记录给 AI 使用的长提示词（含 outerHTML 等大段
    代码）。此类内容占版面大、阅读打断感强。引用块功能将其折叠为
    一个微型图标，使正文保持清爽，点击即可查看完整代码。

  13.1.2 交互流程
    · 添加方式（两种，互为补充）：
      a) 智能识别：用户粘贴/输入包含长代码（如 <div...></div>
         结构、JSON、SQL、脚本等特征）的文本时，自动弹出
         轻提示"检测到长代码，是否折叠为引用块？"，用户确认后折叠；
      b) 手动添加：选中目标文本 → 右键菜单"折叠为引用块"。
    · 折叠后效果：在正文中仅保留一个约"三个汉字"宽度（约 42px ×
       20px）的小长方形图标，作为该引用块的占位符。
    · 展开查看：单击该图标 → 以弹层（仿现有文字颜色选择器的
       滑入/淡入动画）或编辑器内嵌展开面板显示完整 outerHTML 代码，
       并支持全选复制；再次点击或点击外部区域收起。
    · 引用样式：图标外观仿"引用/代码"样式——浅灰蓝底、圆角矩形、
       左上角显示小引号或 </> 角标，带 hover 高亮与 press 反馈。

  13.1.3 视觉与动效规范
    · 占位图标尺寸：42 × 20 px（约三个汉字宽），圆角 5px
    · 默认状态：浅灰底 #EEF0F5 + 深蓝图标 #25314C
    · hover 状态：底 #F0F0F0、图标 #25314C（180ms OutCubic）
    · press 状态：底 #FFFFFF + 白色发光阴影（150ms OutCubic）
    · 展开弹层：从图标下方展开，淡入 + 上滑（220ms OutCubic），
       关闭时反向（160ms InCubic），与颜色选择器动画体系一致
    · 展开面板内代码区：等宽字体（Consolas 等）、字号 12px、
       背景 #FAFAFA、边框 1px #E5E5E5、圆角 8px，可横向滚动
    · 折叠/展开全程禁止突变，遵循非线性缓动红线

  13.1.4 数据与存储规范
    · 引用块作为内容的一部分随笔记 HTML 持久化存储
    · 建议采用自定义占位元素保存，例如：
          <span data-refblock="uuid" data-title="..."></span>
    · 代码原文单独存入独立存储（如引用块资源表 refblocks.json，
       或随 notes.json 内联），保证切换笔记、重启软件后仍可还原
    · 删除占位图标时提示"同时删除对应代码原文？"，防止数据残留
    · 原有原子保存链路必须保持，写入不可破坏既有 notes.json 格式

  ──────────────────────────────────────────────
  13.2 计划二：AI 提示词优化助手
  ──────────────────────────────────────────────

  13.2.1 功能背景与目标
    为已写好的提示词提供"二次打磨"能力：借助未来接入的某一 AI
    API 与开源提示词撰写 Skill，对选中的提示词进行结构化、优化，
    且不覆盖用户原文，而是生成在原文下方的新段落中，便于对比与
    择优使用。

  13.2.2 交互流程
    · 触发方式（两种）：
      a) 快捷键：鼠标左键选中目标文本后，按预设快捷键
         （建议 Ctrl+Shift+O 或用户可自定义）；
      b) 右键菜单：选中文本 → 右键菜单"AI 优化提示词"。
    · 流程：
      1) 读取当前选区文本（仅纯文本，不含格式）；
      2) 调用 AI API（未来接入，接口以插件形式解耦）；
      3) 请求中注入开源提示词撰写 Skill 指令，要求保持原意、
         只做结构与表达优化；
      4) 结果插入：在当前选区（光标所在段落）下方另起新段落，
         生成优化后的提示词，原内容完全不动；
      5) 优化结果与原文之间以分割线（沿用现有 <hr> 逻辑）分隔，
         并自动追加一行标注（如"—— AI 优化版 ——"）。
    · 状态反馈：调用期间顶栏状态区显示"AI 优化中…"，完成后
       切回"编辑"，沿用现有状态标签渐隐渐入动画。

  13.2.3 视觉与动效规范
    · 优化结果段整体不套用特殊背景，仅用分割线 + 灰色标注行区分，
       保证与现有纯白/纸张黄背景兼容
    · 标注行：11px、灰色 #9A9A9A、常规字重
    · 插入动画：新段落滚动进入可视区（无跳动），如必要可做
       轻微高亮淡出（底色 #F0F0F0 渐隐，600ms OutCubic）
    · 右键菜单沿用现有 QMenu 风格，新增项图标为纯色 SVG（24px）

  13.2.4 技术与扩展规范
    · AI API 层以抽象接口设计（如 AiProvider 基类），便于后续
       更换/同时支持多家服务，禁止硬编码单一厂商
    · 密钥与配置不写入 notes.json，独立存储于配置文件，且不随
       笔记导出；遵循最小权限原则
    · 开源提示词 Skill 以资源文件形式随软件分发，可版本化更新
    · 调用失败不得影响本地内容，选区原文保持不动，仅提示失败
    · 网络请求须带超时与取消机制（用户可中断）
    · 隐私约定：仅将用户选中的文本发送至 AI 服务，绝不发送整篇
       笔记或其他笔记内容；设置中提供"允许发送"开关

  ──────────────────────────────────────────────
  13.3 两个计划的共同要求
  ──────────────────────────────────────────────

    · 新功能所有按钮/图标/弹层必须遵循本规范第一至十二章全部约定
      （配色、圆角、字号、动效、图标尺寸、原子保存等）
    · 不改变现有笔记数据字段语义，存量数据读取保持向后兼容
    · 每个功能上线前需走崩溃防护与自动保存链路回归验证
    · 计划排期与优先级由产品方后续确认，本章节仅作为设计基线

────────────────────────────────────────────────────────────────────────
十四、SVG 图标设计规范
────────────────────────────────────────────────────────────────────────

  本章节面向图标设计与重绘（当前重点：文字大小、粗体、下划线、
  删除线、分割线五个待重绘图标），规定 SVG 源文件的统一技术格式
  与视觉要求。所有新增/修改的图标必须满足本章全部约束方可入库。

  14.1 基准尺寸（硬性要求）
  ┌──────────────┬──────────────────────────────────────────────┐
  │ 校验尺寸     │ 16 / 32 / 64 px                              │
  │ 渲染原理     │ SVG 矢量源，运行时 SvgIconLoader 以 1024px    │
  │              │ 超采样渲染 → 内容包围盒归一化 → 按需缩放居中  │
  │ 设计要求     │ 16px 最小档仍清晰可辨、不断线、不糊；         │
  │              │ 32px 为标准档；64px 校验细节与圆角            │
  └──────────────┴──────────────────────────────────────────────┘
  · 实际运行时：编辑工具栏图标渲染为 24px（按钮 30×26 内），
    设计只需保证 16px 清晰即可覆盖全部场景。

  14.2 技术硬性要求（违反将导致渲染错误）
    1. viewBox 必须为 0 0 24 24（统一 24 网格设计画布）
    2. 必须为【单 path + 单色 fill】，禁止多 path 双色图标
       （SvgIconLoader 会把所有 fill 统一替换为主题色，双色中
        的"挖空白"会被同色填充 → 变成实心块，如下划线现稿）
    3. 禁止使用 stroke 描边（加载器只替换 fill，stroke 不会被
       着色，会残留 #25314C / 黑色）
    4. 基准色统一 fill="#25314C"（深蓝黑，运行期替换为主题色）
    5. fill 可内联书写，或沿用 .cls-1 类写法（加载器自动剥离
       <defs><style> 并补内联 fill，两种均可）
    6. 内容主体四周留白 ≥ 2px（相对 24 网格），禁止顶满画布
    7. 文件保存为 SVG 1.1，无外部引用/滤镜，英文小写命名

  14.3 视觉硬性要求
    1. 线宽/笔画：视觉线宽 1.5~2px（24 网格），保证 16px 下
       仍 ≥1px、不断线
    2. 圆角：外轮廓圆角 1~2px，禁止尖锐直角，与现有 Magicoon
       图标（palette、pen、arrow-down 等）风格一致
    3. 视觉重心：图形居中、左右上下光学平衡（横线类图标需
       视觉居中而非数学居中）
    4. 语义明确：一眼可辨"粗体 / 字号 / 下划线 / 删除线 / 分割线"

  14.4 五个待重绘图标的具体要求
  ┌─────────────┬───────────────────────────────────────────────┐
  │ 图标        │ 设计要求                                       │
  ├─────────────┼───────────────────────────────────────────────┤
  │ 粗体  bold  │ 标准 "B" 字形：左侧竖脊 + 上下两个饱满圆腹，    │
  │             │ 无外框、无多余装饰；线宽与下划线/删除线统一      │
  │ 文字大小     │ "A/a" 组合：大 "A" 为主体，小 "a" 置于右上或    │
  │ font-size  │ 右下，去除现有外框，主次分明、双字母简洁         │
  │ 下划线      │ 标准 "U" 字形 + 底部横线：横线宽约字形腰宽的     │
  │ underline  │ 60%~70%，距字形底缘 1~2px，线宽 2px             │
  │ 删除线      │ 标准 "S" 字形 + 水平线横穿字腰：线两端各略超出   │
  │ strike     │ 字形左右边缘约 1px，线宽 2px，与下划线呼应        │
  │ 分割线      │ 两条等长圆角横线垂直居中：间距 5~6px、线宽 2px、 │
  │ divider    │ 长度约占画布 80%，与现有 divider 风格保持一致     │
  └─────────────┴───────────────────────────────────────────────┘

  14.5 现有问题诊断（重绘原因）
    · 粗体 / 文字大小 / 下划线 / 删除线 现为 1024×1024 图标库
      导出，存在以下问题：
      - 笔画粗细不统一、图形复杂（删除线为复杂 S 轮廓带装饰）
      - 文字大小带外框、视觉繁琐
      - 下划线为双色（白挖空会被同色替换成实心块）
    · 分割线已是 24×24 Magicoon 双横线，作为其余四个图标的
      风格基准
    · 重绘后统一为：24 网格 + 单色单 path + 2px 级线宽 + 圆角，
      与全应用图标体系完全一致

  14.6 入库与验证
    · 新图标放入 icons/ 目录，命名与 qrc 中一致：bold、font-size、
      underline、strikethrough、divider
    · 验证：分别在 16 / 32 / 64 px 三档检查清晰度与可辨识度；
      并在软件工具栏 24px 下与 palette、pen 等图标对比视觉重量
    · 替换后重新构建（ninja）并冒烟测试工具栏渲染

      · 稳定版    ：%APPDATA%\MicroPrompt\MicroPrompt\notes.json
      · 开发版    ：%APPDATA%\DesktopNotesDev\DesktopNotes\notes.json
      · 对外测试版：%APPDATA%\DesktopNotesTest\DesktopNotes\notes.json
    开发版已移除旧数据迁移逻辑，绝不读取稳定版笔记；
    首次启动仅从 exe 同目录「测试笔记/prompts.json」预置测试提示词。

  15.3 合并流程（开发版 → 稳定版）
      1. 仅同步代码文件；
      2. 笔记数据位于 %APPDATA%，合并不触碰任何数据文件，
         保证稳定版笔记零丢失；
      3. 合并后重新构建稳定版。

  15.4 构建约束
    三个版本目录均为中文路径，MinGW 工具链构建前需先映射为
    ASCII 盘符：subst Z: "<版本目录>"，构建完成后 subst /D Z: 清理。
